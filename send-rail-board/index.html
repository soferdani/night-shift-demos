Why this is the night-4 milestone

1

The board is markdown, not a web page

Obsidian mobile renders it natively. Every code block gets a copy button the app already provides, so the one thing he has to do is one tap on a screen he was already looking at.

2

The taps carry the text, not a summary

wa.me and Gmail compose links open with the message already typed. A link too long to survive the URL says so instead of opening an empty window.

3

One card, not twenty-one

One message gets its full text. Four get the taps only — the text is inside the link, so nothing is lost. The rest fold to one line each. The board answers “which one do I open”, not “what is in all of them”.

4

It still never sends anything

Same rule as every night: the rail opens an app with the text ready. The send is his.
